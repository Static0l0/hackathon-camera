## Design system

`DESIGN.md` is the TypeUI "Editorial" system, generated by the `typeui.sh` CLI
(v0.7.1, MIT). It contributes tokens only — a colour palette, a type scale, radii and an
8pt spacing grid. No TypeUI code, markup or stylesheet ships in the page: `typeui.sh` is
not imported anywhere in `src/`, `index.html` or `vite.config.js`, and the generated
`DESIGN.md` is a document, not a dependency.

The page's art direction deliberately departs from that system in eleven documented
places; `DESIGN_NOTES.md` lists every override and why, and `scripts/contrast.mjs`
re-measures the palette the page actually uses.

## Algorithm references (no code taken)

The Malvar–He–Cutler coefficients were read from the original paper and the IPOL
reference implementation, and the Hamiltonian/Adams gradient test from the original
Hamilton–Adams paper. The implementations here are this project's own; the papers are
references, not dependencies. `tests/demosaic.test.js` asserts properties that would fail
if a coefficient were mistyped (kernels sum to 8, each kernel matches its transpose,
flat fields reproduce exactly).
