One pixel is four layers deep

A microlens gathers light, one filter passes a single colour, a diode counts the electrons, and a circuit reads the number out. The cloud is that count — sampled when there are too many dots to draw, with the rate printed below.

  1. 01 Microlens — gathers light
  2. 02 Colour filter — passes one colour
  3. 03 Photodiode — counts electrons
  4. 04 Circuitry — reads the count

One colour per pixel

Two of every four sites are green, because green carries most of the detail.

The RGGB pattern repeats every two pixels in both directions. A red site never measures green or blue. Those two numbers have to be guessed — which is what the next section does.

Make the guess yourself

At a red or blue pixel there is no green reading. Choose which neighbours to trust, then see what each algorithm actually did.

Every method rebuilds green first, then fills red and blue from colour differences. The differences stay smooth across an edge even when the colours jump.

Reconstruction quality per method
MethodPSNRColour error

Nearest neighbour assumes a neighbour is close enough, so edges zip. Bilinear assumes the image is smooth in every direction, so diagonals smear. Hamilton–Adams assumes an edge has one axis, so it commits and can staircase. Malvar–He–Cutler smooths what it cannot see, which lowers the average miss and blurs fine colour.
