A pixel has four layers

Light passes through a lens and a colour filter. A sensor site counts the electrons. A circuit reads the count. Each dot is part of that count. When there are too many dots, the page draws fewer and prints the rate below.

  1. 01 Microlens — gathers light
  2. 02 Colour filter — passes one colour
  3. 03 Photodiode — counts electrons
  4. 04 Circuitry — reads the count

One colour per pixel

Each site has one filter. Two of every four filters are green. The eye sees green detail best.

This RGGB pattern repeats every two sites. A red site never measures green or blue. The camera must guess those two numbers. The next section shows how.

Make the guess yourself

A red or blue site has no green reading. Choose a pair of green neighbours. Then see what each algorithm chose.

Each method builds the green layer first. It then fills red and blue from colour differences. Those differences stay smooth across an edge, even when the colours change sharply.

Reconstruction quality per method
MethodPSNRColour error

Nearest neighbour copies one pixel, so edges look like a zip. Bilinear uses a smooth average, so diagonal edges smear. Hamilton-Adams picks one direction, so an edge can look like steps. Malvar-He-Cutler smooths the error it cannot see, so fine colour blurs.
