A camera only measures one colour per pixel

A sensor is a grid of tiny spots called sites. Each site sits under one colour filter, so it counts one colour only.

A pixel is the dot in the finished photo. Two of its three colour numbers were never measured — software guesses them.

PSNR 41.5 dB is the guess score: how close the guess is to the real picture, higher is better. SNR 28.0 dB is the signal score: how far the signal sits above the noise.

Four layers above every pixel

Start with one site. Light passes a microlens, which gathers it. Then a colour filter, which keeps one colour. Then a photodiode, which counts the electrons that land. Then a circuit, which reads the count.

03

One colour per pixel

Each site has one filter, so it records one colour. The filters repeat every two sites: red, green, green, blue. Half of them are green, because your eye reads green detail best.

RGRGRG GBGBGB RGRGRG GBGBGB RGRGRG GBGBGB
red sites25%
green sites50%
blue sites25%

A red site never records green or blue. Those two numbers aren't stored somewhere else in the file — they were never there.

So the camera fills each missing colour from the neighbours it does have. That's a guess. The next section is about how the guess is made.

04

The missing green

A red or blue site has no green reading. Its two green neighbours — one along the row, one down the column — are all the evidence there is. Pick one and see which answer lands closer.
